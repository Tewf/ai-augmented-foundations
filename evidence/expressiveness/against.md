# Against: the controversies and the failures

Evidence against the readings in [review](review.md). None is deleted to make a claim stronger.

## Against a computable cost

- Scalabrino 2021: none of 121 metrics captured code understandability in the ratings used (secondary). A count is not a measure.
- Muñoz Barón 2020 concludes that code understanding is measured in many ways and that how they relate is unknown (secondary). A validation against one of them says little about the others.
- Campbell 2023 is the owner's account of its own metric. Its validation is Muñoz Barón 2020, by other authors, and covers code.

## Against cognitive load theory as the basis

- De Jong 2010 lists conceptual, methodological and application problems in the theory (secondary, abstract). The capacity limit is solid (Cowan 2001); the theory built on it is contested.
- Cowan 2001 puts the limit at three to five chunks and says it holds only when chunks can be identified. What counts as a chunk in a tree of topics is not given.

## Against formality

- Shipman 1999 reports experience in which requiring formal representations harmed users (secondary, record only). A strict tree of typed topics has this cost, which the review has not measured.

## Against reading a theorem as a rule

- Treewidth and the MSO logic are results about graphs. A reader of a tree of topics does not run an algorithm over a decomposition. The step from a bound on a program to a cost for a person is an analogy, with no study.
- HTN language classes concern plans, not documents. The class of a topic tree is not known.
