# Expressiveness: what a tree of topics holds and costs

What a tree of topics can encode, and a number a program can compute for what it asks of a reader. Both come from
the [expressiveness review](../../evidence/expressiveness/README.md). The standard's own rules for depth and breadth
([shallow outline](https://github.com/Tewf/reader-ergonomics/blob/2e5b6f0c3e67d2dc8195a63cf882d46170e79a5a/principles/document/shallow-outline.md),
[browsable folders](https://github.com/Tewf/reader-ergonomics/blob/2e5b6f0c3e67d2dc8195a63cf882d46170e79a5a/principles/collection/browsable-folders.md))
are the parts the cost adds up.
