# Principles

The principles this repository adds, in two groups. Each follows the format of the reader-ergonomics principles and
carries the grade its review gave. A principle the standard already holds is linked, never restated here.

| Group | What it covers |
|---|---|
| [Expressiveness: what a tree of topics holds and costs](expressiveness/README.md) | the links beside a tree, and a computed cost of a tree |
| [Convergence: when a project stops](convergence/README.md) | stopping at an acceptable result, with the optimum as a bound |
